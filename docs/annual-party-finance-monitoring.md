# 政黨年度財務監測

政黨年度財務依《政黨法》由內政部集中受理與公開，不需要追蹤各政黨自己的公告。這份資料與監察院政治獻金會計報告不同，兩者不得合併成同一組收入構成。

## 頻率

- 每年 7 月中旬檢查一次上一年度申報。
- 每年 8 月底再檢查補正、追認與官方 PDF 是否更新。
- 平時不納入每日或每週監測。

## 本機執行

取得內政部申報索引：

```bash
npm run fetch:party-annual-finance
```

先比對本機政黨、不寫資料：

```bash
npm run stage:party-annual-finance
```

確認來源與身分配對後，只套用到完整本機 Supabase：

```bash
npm run monitor:party-annual-finance:local
```

產物位於 `tmp/party-annual-finance/`。

## 公開邊界

- 官方申報狀態、追認狀態、黨員代表大會通過狀態及官方連結，可在政黨名稱唯一配對後公開。
- 找不到或同時命中多個本機政黨的資料不得寫入，必須留在 staging 結果。
- 內政部掃描 PDF 的金額不得直接使用 OCR 結果公開；人工覆核後才能加入收入、支出、資產或負債圖表。
- 所有寫入命令都必須拒絕非 loopback Supabase。
- 正式 Supabase 仍須走獨立發布與核准流程。

## UI

- 「政治獻金」呈現監察院的捐款來源、支出與公司捐贈摘要。
- 「政黨年度財務」呈現內政部申報狀態與官方財報。
- 年度財務金額尚未人工覆核時只顯示狀態卡與官方連結，不顯示空值或 OCR 推測圖表。
