# 2026 我的選票：資料覆蓋與本機驗證

功能分支：`codex/ballot-mapping-phase1`。只做可逆本機程式與資料對應；沒有正式資料寫入、提交、推送或部署。

## 查詢與資料邊界

`apps/web/src/lib/myBallot.ts` 的 `queryMyBallot` 使用既有事件 `2026-2026-11-28-local`、戶籍行政區代碼與裝置端查詢類別。每一職務最多一張，不把區域及原住民議員票相加；同日其他投票不混計。候選人是否公布、資格是否審定不影響選區對應。

四種結果：`confirmed`（選區範圍已確認）、`needs-setting`（指出缺哪項設定）、`missing-data`（來源未收錄）、`ambiguous`（分配重疊或來源明示疑義）。只有所有適用票種都確認才顯示預估張數；不推算年齡、居住期間或個別名冊資格，實際可領選票以選舉人名冊為準。

選區確認與既有 race 頁連結分開。沒有 race UUID 時仍顯示正式範圍與票種，另標「選區頁連結待補」。不從候選人名單推測選區，不捏造 UUID，不將2022範圍冒充2026公告。

## 類別適用依據

未填查詢類別保留 `unspecified`；所有類別確實共用同一選區時仍可確認，不能直接把未設定轉成一般。村里長、地方首長與一般山原區代表，以行政區居民的選舉人資格認定；候選人身分限制不能當作選民限制。

議員或民代表有該類原民專席時，該類別只配專席；沒有該類專席時，配同戶籍的普通區域席。以完整2026公告確認「無專席」，不能因某次查詢漏資料就自動退回普通席。相關依據：

- [現行選罷法](https://law.cec.gov.tw/LawContent.aspx?id=GL000292)第15、16、20、36條：一般選舉人資格、原民專屬選舉、名冊及行政區／原民分區。
- [中選會111年選務手冊](https://web.cec.gov.tw/api/file/1cefbc0f-0e81-4772-aadc-149f6432c1a2.pdf)印刷頁134–135：普通鄉鎮市民代表以行政區域分區、平地原民專席另分，山原區代表以該區行政區域為選區；村里長以村里行政區域為選區。已下載並讀取本機文字，沒有使用該年度分區或名單。
- [新竹市選委會111年講習教材](https://web.cec.gov.tw/api/file/c5b9500d-cd3c-4d22-8884-cae63cd8af24.pdf)明載當時該市無山原議員票時，山原選民仍領區域議員票。此為配票規則佐證；2026該市已公告山原議員選區，程式依2026專席分配，不沿用111年無專席情形。

未宣稱已核閱尚未取得的115年完整名冊作業手冊。

## 重建與維護

- `python3 scripts/build-ballot-mappings-2026.py`：縣市長、議員原始範圍及既有 race UUID。
- `python3 scripts/build-village-ballot-mappings-2026.py`：村里長、鄉鎮市長及山原區長；讀取已下載官方原稿，產生共享來源及精簡村里表。`--check` 檢查重建一致性；`--chief-only` 單獨處理地方首長。
- `python3 scripts/build-representative-ballot-mappings-2026.py`：由已核對的分區原文解析行政碼，檢查村里覆蓋、重複及既有 race 連結。
- 所有重建均不連線資料庫、不寫正式環境。來源原文、腳本及前端產物屬共用審查資料；下載與中間研究檔保留本機。
- 行政碼純數字，不含UI用的 `district-`／`village-` 前綴。字形正規化只用於精確範圍內的代碼配對。

## 設定與介面

沿用 `public-office-watch.voting-region-preference.v1`，不清除舊戶籍。類別只存localStorage，不進分享網址、不傳API。只有受影響票種提示補縣市／鄉鎮市區／村里／必要鄰別。手機順序為戶籍摘要、日期倒數、我的選票、投開票所摘要、候選人及其他探索。桌機維持原地圖與首頁，摘要補票數及查詢入口；三個入口共用既有設定樣式視窗，提供「我的選票／投開票所／戶籍設定」分頁，首頁不插入或展開查詢內容。未設定時先顯示設定，儲存後返回原查詢；查詢中修改設定也保留返回目標。標頭及分頁固定、內容內部捲動，關閉恢復入口焦點且不改首頁捲動位置，進入選區頁會關閉視窗。手機仍直接呈現選票與投開票所。瀏覽其他縣市不覆蓋戶籍。
