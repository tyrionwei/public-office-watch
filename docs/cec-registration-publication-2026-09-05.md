## 工具與重現

工具只接受完整本機專案 `public-office-watch`，不讀取正式資料庫連線。

```sh
# 核對、試跑全部更新與公開資料檢查，最後回復交易
node scripts/publish-cec-registration-local.mjs

# 套用本機並更新公開資料
node scripts/publish-cec-registration-local.mjs --apply-local

# 全量計數、跨縣市匿名查詢及新增村里選區驗證
node scripts/verify-cec-registration-publication.mjs
node scripts/verify-cec-registration-publication.mjs --rehearsal
```

需要上一批保存的 `tmp/cec-registration-final/` 來源檔案、prepared-import.json、import-rows.json 與 import-manifest.json。工具檢查審核狀態及內容漂移，不會重設後續資格、號次或參選狀態；任一檢查失敗即回復整筆交易。

實際套用紀錄：`tmp/cec-registration-publication/2026-09-04T16-22-27-187Z-apply.json`，時間為 UTC。紀錄包含修改前的未公開人物／選區完整資料，以及新增公開的參選與事件識別，可用於回復。本機公開版本：`d69be3f0-a3fa-4c86-b7bc-c25fd85ad5d3`。
