# 每日人物重大事件監測

這個流程用於每天找出可能影響人物公開資料的新聞線索。它只產生待審清單，不會直接修改人物黨籍、參選狀態、公職狀態、司法紀錄或公開資料。

## 監測範圍

- 黨籍異動：退黨、入黨、開除或恢復黨籍。
- 參選異動：退選、撤回登記、停止競選或候選資格變動。
- 公職異動：請辭、停職、解職、罷免、遞補或補選。
- 司法程序：搜索、約談、聲押、羈押、交保、起訴、判決與定讞。

一般政治評論、政策攻防、民調與私人生活新聞不在此流程內。

## 優先人物

監測名單取自公開人物目錄，優先包含：

1. 現任公職人員。
2. 即將到來選舉的候選人。
3. 2022 年以後曾參選或任職的人物。

同名人物一律標記為需要人工確認，不自動合併。

## 執行

執行完整的每日唯讀檢查（既有資料同步預覽，加上新聞監測）：

```bash
npm run monitor:daily
```

完整流程若收到 `degraded`、`partial`、`failed` 或 `needsAttention: true`，會在輸出摘要後以非零狀態結束，供排程器發出通知。

```bash
npm run discover:daily-person-news -- --output tmp/daily-person-news.json
```

和前一次結果比較，只辨識新線索：

```bash
npm run discover:daily-person-news -- \
  --previous tmp/daily-person-news-previous.json \
  --output tmp/daily-person-news.json
```

預設查看最近 36 小時，也可暫時調整：

```bash
npm run discover:daily-person-news -- --lookback-hours 48
```

每日人物流程另有家族、黨籍與司法三類的逐人搜尋。每位人物首次補查不加日期限制；三類都查詢成功後，滿 30 天冷卻期即可再次監測。每日 25 人約半保留給到期監測、其餘繼續歷史補查；若排隊或來源失敗超過 30 天，查詢範圍會從上次三類皆成功的日期動態延長並多保留一天重疊。完整 `monitor:daily` 會自動執行，也可單獨執行：

```bash
npm run discover:daily-person-research-news
```

保留的 `discover:daily-person-legal-news` 指令只供單獨診斷司法搜尋器，並非完整每日人物研究流程。

## 審核原則

- Google News RSS 僅作為新聞發現索引；審核時應開啟原始媒體頁面。
- RSS 查詢不加入人物姓名；符合事件詞的新聞即使無法對上既有人物，也會以 `unmatched_person` 保留待審。
- 標題出現姓名和事件詞只代表可能相關，不代表事件主體一定是該人物。
- 黨籍與公職異動應再找政黨、本人或主管機關等直接來源。
- 司法線索應再依既有司法紀錄流程確認身分、案號、程序階段和判決結果。
- 媒體消息即使可信，也只能建立待審資料；通過審核後才進入正式發布流程。
- 逐人研究要求關係、黨籍或法律詞直接描述目標人物；較弱的姓名配對保留為程序待審，不會直接跳過或建立公開紀錄。
- 新聞確認具體罪名、年份與程序後，才搜尋司法院官方刑事裁判；不可只憑同名合併。

## 安全邊界

- 程式只讀公開人物目錄與新聞 RSS。
- 報告不保存新聞全文，只保留標題、來源、時間和短摘要。
- `autoPublish` 固定為 `false`。
- 不提供任何直接寫入正式資料庫的參數。
