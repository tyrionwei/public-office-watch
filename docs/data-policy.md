# Data Policy

## 可用資料來源

僅使用官方或可信公開來源，例如：

- 中選會
- 監察院財產申報
- 監察院政治獻金
- 經濟部商工登記
- 公開資訊觀測站
- 政府電子採購網
- 司法院公開裁判書
- 地方議會公開資料
- 官方公告
- 可信新聞媒體

## 禁止事項

- 不使用需繞過權限的資料
- 不使用非公開取得資料
- 不登入非必要網站
- 不繞過 CAPTCHA 或 robots 限制
- 不提交 secrets

## 個資與風險限制

不得蒐集或輸出：

- 身分證字號
- 完整住址
- 私人電話
- 私人 email
- 未成年子女姓名
- 未公開親屬資料
- 私人社群帳號
- 未經證實爆料

### 出生日期

目前開放蒐集及公開政治人物／候選人的完整出生日期，預設公開顯示完整生日，用於人物辨識及同名比對。限使用官方或可信公開來源已公開的日期，確認來源、人物身分及與公職資訊或身分辨識相關的用途；不得推測缺漏月日、由私人資料補齊，或延伸蒐集家屬生日。

公開展示前，仍須核對蒐集與利用依據、日期正確性及展示完整日期的必要性。依法公開的選舉公報可作來源；Wikipedia、Wikidata、VoteTW 的既有公開紀錄可作查核線索，但第三方長期公開本身不替代本站的來源與利用判斷。來源衝突、人物歸屬不明或收到更正／停止利用要求時，先停止使用有疑義的日期並處理查核；只有年份可靠時，不補成完整日期。

《個人資料保護法》第2、5、19、20條規範個資及蒐集／利用條件；《公職人員選舉罷免法》第47條規定相關選舉公報列載出生年月日及網站公開。這些規定不是所有人物生日的全面公開許可，也沒有完整生日一律不得公開的禁令。[個資法](https://law.pdpc.gov.tw/LawContent.aspx?id=FL010627)、[選罷法](https://law.cec.gov.tw/LawContent.aspx?id=GL000292)。

身分比對強度另依 [Current Data Rules](current-data-rules.md)；已知生日相符不能單獨核准合併，私人比對用途也不自動授權公開。

管理員可在「公開更新動態管理」的「生日公開顯示」區塊，全站切換「僅顯示出生年份」。這只調整網站生日欄位的顯示粒度，不刪除或縮減原始日期、來源claim與身分比對資料，也不撤銷既有公開資料API的存取；不是逐人設定或資料下架機制。管理員比對畫面仍可使用完整日期。新開啟／重新整理的人物頁讀取目前設定；已開啟且可見的頁面每分鐘或重新取得焦點時更新。設定無法讀取時暫時只顯示可辨識的年份，避免使用不明的完整日期顯示設定。

## 發布政策

- 未審核資料不得標記為 `verified`
- 未審核資料不得標記為 `is_public = true`
- D 級資料不可自動公開
- C 級資料建議人工確認後公開
