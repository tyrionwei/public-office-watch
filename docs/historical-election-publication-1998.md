# 1998 議員選舉分批公開紀錄

## 範圍

- `1998年縣市議員選舉`：投票日 `1998-01-24`，23 個縣及省轄市、194 個選區、1,952 位候選人。
- `1998年直轄市議員選舉`：投票日 `1998-12-05`，臺北市與合併前高雄市、13 個選區、215 位候選人。
- 合計 2 場選舉、25 個歷史行政區、207 個選區、2,167 位候選人與 2,167 位 canonical 人物。
- 本批僅處理 1998 年議員選舉，不包含 1994 年及更早資料。

官方日期來源：

- 中選會1994至2006各項選舉性別統計：`https://web.cec.gov.tw/api/file/eaf5ae88-e2d8-4e87-be37-6ad517adbda5.pdf`
- 中選會第246次委員會議紀錄：`https://web.cec.gov.tw/api/file/51e9ad6e-bf55-4945-b21e-9aeaa0e74f40.pdf`
- 中選會87年直轄市議員公報目錄：`https://bulletin.cec.gov.tw/01%E9%81%B8%E8%88%89%E5%85%AC%E5%A0%B1/05%E7%9B%B4%E8%BD%84%E5%B8%82%E8%AD%B0%E5%93%A1/`

## 選舉與行政區修正

- 原本合併為一場的1998議員選舉，依官方投票日拆為縣市與直轄市兩個事件。
- 桃園14個選區、168位候選人原本誤接現代桃園市，已改接歷史桃園縣並修正選區名稱與類型。
- 臺中市、臺南市改接縣市合併前的省轄市區域。
- 高雄市改接合併前的直轄市區域，不再指向現代高雄市。
- 選區名稱沒有 `第01選舉區`、`第02選舉區` 等前導零。

## 得票資料

- 中選會來源包含2,167位候選人的完整得票數、得票率與當選狀態。
- 205位候選人原本已有得票資料；本批回填其餘1,962位。
- 回填只更新既有候選人，沒有新建人物或候選人，也不改動其他年份。
- 回填 migration 以 `--year 1998` 鎖定年度，並同步正式環境可能尚未更新的來源快照。

## 人物身分

- 臺北市第3選舉區陳淑華曾被姓名規則誤接臺中市同名人物，錯誤配對已駁回；來源人物仍接到正確的臺北市陳淑華。
- 同一年度共有6組同名候選人：吳天福、鄭輝煌、陳光宇、陳益昌、陳秀惠、陳長榮。
- 6組均在同一次選舉登記不同選區，已各建立A級「不同人」決策。
- 同一選區沒有 canonical 人物與候選號碼重複，也沒有涉及本批人物的未完成重複審核。

## 公開與驗證

- 公開2場選舉、25個相關歷史區域、207個選區、2,167位候選人與其canonical人物。
- 候選號碼、政黨、得票、當選狀態、候選資格與結果狀態均完整。
- 更新 `public.public_people_list_cached` 後執行 `published.promote(NULL)`。
- `published.elections`：2筆。
- `published.races`：207筆。
- `published.candidate_facts`：2,167筆。
- 隔離正式環境的匿名API可讀取正確的兩場事件、207個選區與2,167位候選人。
- 112項資料匯入、身分比對、聊天室與migration測試通過。
- 公開介面smoke test通過；內部release、promote與人物配對資料仍不可由匿名角色讀取。

## 容量

- 隔離正式環境：333 MiB（349,400,211 bytes）。
- 2002批次完成後基準：330 MiB（346,434,707 bytes）。
- 本批增量：約2.8 MiB。
- 距350 MiB內部警戒線約17 MiB，距Supabase Free 500 MiB上限約167 MiB。
- 350 MiB只是提前警戒線，後續批次仍可繼續，但每批都要重跑隔離容量預演。

## 狀態與下一步

- 本批migration目前只套用於本機Supabase與隔離rehearsal，尚未部署正式Supabase。
- 下一批可盤點1994年議員選舉；仍需獨立處理投票日、行政區、人物身分與容量，不得由1998 migration自動擴大範圍。
