# 2002 議員選舉分批公開紀錄

## 範圍

- `2002年縣市議員選舉`：投票日 `2002-01-26`，23 個縣及省轄市、195 個選區、2,058 位候選人。
- `2002年直轄市議員選舉`：投票日 `2002-12-07`，臺北市與合併前高雄市、13 個選區、228 位候選人。
- 合計 2 場選舉、25 個歷史行政區、208 個選區、2,286 位候選人與 2,286 位 canonical 人物。
- 本批僅處理 2002 年議員選舉，不包含 1998 年及更早資料。

官方日期與公報來源：

- 中選會第304次委員會議紀錄（91年縣市議員選舉）：`https://web.cec.gov.tw/api/file/069e9429-d81c-4872-a377-e4cecfecdaf5.pdf`
- 中選會91年高雄市議員選舉統計：`https://web.cec.gov.tw/central/article/21248`
- 中選會91年臺北市議員選舉公報目錄：`https://bulletin.cec.gov.tw/?dir=01%E9%81%B8%E8%88%89%E5%85%AC%E5%A0%B1%2F05%E7%9B%B4%E8%BD%84%E5%B8%82%E8%AD%B0%E5%93%A1%2F091%E5%B9%B4%2F01%E8%87%BA%E5%8C%97%E5%B8%82`

## 選舉與行政區修正

- 原本合併為一場的2002議員選舉，依官方投票日拆為縣市與直轄市兩個事件。
- 桃園選區改接歷史桃園縣，並將選區名稱與類型改為縣議員。
- 臺中市、臺南市改接縣市合併前的省轄市區域。
- 高雄市改接合併前的直轄市區域，不再指向現代高雄市。
- 選區名稱統一使用 `第1選舉區`、`第2選舉區` 格式，沒有 `第01選舉區` 等前導零。
- 後續歷史匯入會依年份把直轄市議員與縣市議員分開，不再只以年份建立一個事件。

## 得票資料修正

- 中選會 `votedata` 的2002資料實際包含完整 `elcand.csv` 與 `elctks.csv`。
- 修正結果解析器，使地方選舉的彙總層級同時接受 `0` 與 `0000`。
- 原住民議員結果維持地方行政區範圍，不再錯當全國性原住民選舉。
- 候選人檔與結果檔的候選號碼欄位不同，配對時改為各自使用正確欄位。
- 216 位候選人原本已有得票資料；本批回填其餘 2,070 位，最後 2,286 位候選人的得票數與得票率均完整。
- 回填 migration 以 `--year 2002` 鎖定年度，不會同時處理其他年份。

## 人物身分

- 2002 同名候選人共有10組；同場不同選區者建立12筆 A 級「不同人」決策，避免姓名相同造成誤合併。
- 臺北市陳淑華誤接臺中市同名人物的來源配對已駁回。
- 合併前高雄市第1選舉區陳美雅與合併後高雄市第6選舉區歷年參選紀錄確認為同一人，建立 verified merge。
- 同一選區沒有 canonical 人物與候選號碼重複，也沒有涉及本批人物的未完成重複審核。
- 既有候選人回填會透過 `person_canonical_map` 與 `race_canonical_map` 驗證合併後身分，不直接比較可能保留為來源 ID 的 UUID。

## 公開規則與驗證

- 公開2場選舉、25個相關歷史區域、208個選區、2,286位候選人與其 canonical 人物。
- 候選號碼、政黨、得票、當選狀態、候選資格與結果狀態均完整。
- 更新 `public.public_people_list_cached` 後執行 `published.promote(NULL)`。
- `published.elections`：2筆。
- `published.races`：208筆。
- `published.candidate_facts`：2,286筆。
- 隔離正式環境的匿名 API 可讀取正確的兩場事件、208個選區與2,286位候選人。
- 112項資料匯入、身分比對、聊天室與 migration 測試通過。
- 公開介面 smoke test 通過；內部 release、promote 與人物配對資料仍不可由匿名角色讀取。

## 容量

- 隔離正式環境：330 MiB（346,434,707 bytes）。
- 2005 批次完成後基準：312 MiB。
- 本批增量：約18 MiB。
- 仍低於350 MiB警戒線與Supabase Free 500 MiB上限，但距警戒線只剩約20 MiB。

## 狀態與下一步

- 本批 migration 目前只套用於本機 Supabase 與隔離 rehearsal，尚未部署正式 Supabase。
- 下一批若處理1998年，需繼續獨立產生年度 migration，並在公開前先重跑容量預演；不得由2002 migration自動擴大範圍。
