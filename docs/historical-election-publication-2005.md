## 歷史行政區修正

- 14 個桃園選區原本誤接現代桃園市，已改為歷史桃園縣及 `county_councilor`。
- 2005 年臺中市、臺南市是合併前的省轄市，已各自建立獨立歷史區域，不再指向現代直轄市。
- 2006 年高雄市是縣市合併前的直轄市，本批一併將其6個已公開選區改指向獨立歷史高雄市。
- 顯示名稱維持當時官方名稱；只有底層區域身分與現代城市分離。
- 後續歷史匯入流程會依選舉年份選擇舊臺中市、舊臺南市及舊高雄市，不再僅依名稱匹配現代區域。

## 人物身分

- 同一選舉內只有一組同名候選人：`楊秀玉`。
- 兩人分別登記嘉義縣第1選舉區與基隆市第7選舉區，維持為不同 canonical 人物。
- 新增 A 級「不同人」決策，避免後續自動流程因姓名相同而誤合併。
- 同一選區內沒有 canonical 人物與候選號碼重複，也沒有尚待人工處理的人物配對。

## 公開規則與資料品質

- 公開選舉、23個相關區域、選區與候選人紀錄。
- 候選人先經 `person_canonical_map` 解析，只公開 canonical 人物。
- 1,135 位 canonical 人物先前已公開，本批新增公開 554 位。
- 被合併的來源人物列維持非公開，避免重複人物進入網站。
- 選區名稱沒有 `第01選舉區`、`第02選舉區` 等前導零格式。
- 候選號碼、政黨、當選狀態與候選資格／結果狀態皆完整。
- 131 筆候選人缺少得票數與得票率，全部位於原住民選區；公開時保留為缺值，不轉成零票。
- 更新 `public.public_people_list_cached` 後執行 `published.promote(NULL)`，同步公開讀取層。

## 驗證結果

- 核心資料：1 場選舉、196 個公開選區、1,689 位公開候選人、1,689 位 canonical 人物。
- `published.elections`：1 筆。
- `published.races`：196 筆。
- `published.candidate_facts`：1,689 筆。
- 隔離正式環境的匿名 API 可讀取 1 場選舉、196 個選區與1,689位候選人。
- 2006 年舊高雄市6個選區在區域修正後仍可由匿名API讀取。
- 23 項歷史匯入、行政區正規化與涵蓋率測試通過。
- 公開介面 smoke test 通過，內部 promote、release 與身分比對資料仍不可由匿名角色讀取。
