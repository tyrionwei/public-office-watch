# 2006 直轄市議員選舉分批公開紀錄

## 範圍

- 選舉：`2006年直轄市及縣市議員選舉`
- 投票日：`2006-12-09`
- 涵蓋區域：臺北市、當時的高雄市
- 選區：13
- 候選人：180
- Canonical 人物：180
- 本批僅處理 2006 年直轄市議員資料，不包含 2005 年及更早地方選舉。

中央選舉委員會的 95 年直轄市議員公報目錄僅列臺北市與高雄市：
`https://bulletin.cec.gov.tw/01%E9%81%B8%E8%88%89%E5%85%AC%E5%A0%B1/05%E7%9B%B4%E8%BD%84%E5%B8%82%E8%AD%B0%E5%93%A1/095%E5%B9%B4/`

投票日另由臺北市選舉公報確認：
`https://bulletin.cec.gov.tw/01%E9%81%B8%E8%88%89%E5%85%AC%E5%A0%B1/05%E7%9B%B4%E8%BD%84%E5%B8%82%E8%AD%B0%E5%93%A1/095%E5%B9%B4/01%E8%87%BA%E5%8C%97%E5%B8%82/%E8%87%BA%E5%8C%97%E5%B8%82%E7%AC%AC4%E9%81%B8%E8%88%89%E5%8D%80%E8%AD%B0%E5%93%A1.pdf`

## 公開規則

- 公開選舉、選區與候選人紀錄。
- 候選人先經 `person_canonical_map` 解析，只公開 canonical 人物。
- 120 位 canonical 人物先前已公開，本批新增公開 60 位。
- 被合併的來源人物列維持非公開，避免重複人物進入網站。
- 更新 `public.public_people_list_cached` 後執行 `published.promote(NULL)`，同步公開讀取層。

## 正規化與資料品質

- 13 個選區皆屬 `city_councilor`，並對應臺北市或當時的高雄市。
- 中選會公報將兩市相關選區命名為 `原住民選舉區`，本批保留官方名稱，不推測拆分成平地或山地原住民選區。
- 選區名稱沒有 `第01選舉區`、`第02選舉區` 等前導零格式。
- 同一選舉內沒有候選人同名，也沒有 canonical 人物與候選號碼重複。
- 2006 候選人沒有尚待人工處理的人物重複審核項目。
- 候選號碼、政黨、當選狀態與候選資格／結果狀態皆完整。
- 6 筆候選人缺少得票數與得票率，全部位於臺北市及高雄市的原住民選區；公開時保留為缺值，不轉成零票。

高雄市公報目錄亦使用 `高雄市原住民選舉區議員`：
`https://bulletin.cec.gov.tw/01%E9%81%B8%E8%88%89%E5%85%AC%E5%A0%B1/05%E7%9B%B4%E8%BD%84%E5%B8%82%E8%AD%B0%E5%93%A1/095%E5%B9%B4/02%E9%AB%98%E9%9B%84%E5%B8%82/`

## 驗證結果

- 核心資料：1 場選舉、13 個公開選區、180 位公開候選人、180 位 canonical 人物。
- `published.elections`：1 筆。
- `published.races`：13 筆。
- `published.candidate_facts`：180 筆。
- 隔離正式環境的匿名 API 可讀取 1 場選舉、13 個選區與 180 位候選人。
- 22 項歷史匯入、行政區正規化與涵蓋率測試通過。
- 公開介面 smoke test 通過，內部 promote、release 與身分比對資料仍不可由匿名角色讀取。
