# 2009 地方議員選舉分批公開紀錄

## 範圍

- 選舉：`2009年直轄市及縣市議員選舉`
- 投票日：`2009-12-05`
- 涵蓋區域：17 個當時的直轄市、縣及市層級區域
- 選區：144
- 候選人：935
- Canonical 人物：935
- 本批僅處理 2009 年地方議員選舉，不包含 2006 年及更早資料。

投票日另以中央選舉委員會資料確認：
`https://web.cec.gov.tw/hcec/article/4033`

## 公開前修正

### 桃園縣歷史行政區

- 原始匯入資料已把 2009 年的 `桃園縣` 轉成現代 `桃園市`，並將 14 個選區誤分成 `city_councilor`。
- 新增獨立的歷史 `桃園縣` 區域，14 個選區改回 `county_councilor`，選區名稱一併改回 `桃園縣第1選舉區` 等當時名稱。
- 歷史來源的建置流程加入年份判斷：2014 年以前的桃園議員資料保存為 `桃園縣`；人物身分比對仍可使用現代 `桃園市` 作為對照脈絡。
- 2014 年起的資料維持 `桃園市`，不受本修正影響。

2009 年桃園縣選舉公報來源：
`https://bulletin.cec.gov.tw/?dir=01%E9%81%B8%E8%88%89%E5%85%AC%E5%A0%B1%2F06%E7%B8%A3%E5%B8%82%E8%AD%B0%E5%93%A1%2F098%E5%B9%B4%2F09%E6%A1%83%E5%9C%92%E7%B8%A3`

### 同名候選人潘政治

- 2009 年屏東縣第3選舉區與第11選舉區山地原住民各有一位 `潘政治`，原資料誤接成同一人物。
- 官方公告顯示兩人於同一場選舉登記不同選區，且黨籍不同；第3選舉區者為民主進步黨，第11選舉區者為無黨籍。
- 本批為第3選舉區候選人建立獨立人物，修正其黨籍，並加入 A 級「不同人」決策，避免後續自動流程再次合併。
- 第11選舉區人物既有的 2014、2018 等歷史連結不變。

官方公告來源：
`https://gazette.nat.gov.tw/EG_FileManager/eguploadpub/eg015243/ch02/type3/gov15/num4/OEg.pdf`

## 公開規則

- 公開選舉、選區與候選人紀錄。
- 候選人先經 `person_canonical_map` 解析，只公開 canonical 人物。
- 被合併的來源人物列維持非公開，避免重複人物進入網站。
- 更新 `public.public_people_list_cached` 後執行 `published.promote(NULL)`，同步公開讀取層。

## 正規化與資料品質

- 144 個選區皆對應當時的行政區與議員類型，未誤接現代桃園市。
- 選區名稱沒有 `第01選舉區`、`第02選舉區` 等前導零格式。
- 平地原住民與山地原住民選區維持明確分類。
- 同一選區內沒有 canonical 人物與候選號碼重複。
- 2009 候選人沒有尚待人工處理的人物重複審核項目。
- 候選號碼、政黨、當選狀態與候選資格／結果狀態皆完整。
- 97 筆候選人缺少得票數與得票率，全部位於原住民選區；公開時保留為缺值，不轉成零票。

## 驗證結果

- 核心資料：1 場選舉、144 個公開選區、935 位公開候選人、935 位 canonical 人物。
- `published.elections`：1 筆。
- `published.races`：144 筆。
- `published.candidate_facts`：935 筆。
- 隔離正式環境的匿名 API 可讀取 1 場選舉、144 個選區與 935 位候選人。
- 22 項歷史匯入、行政區正規化與涵蓋率測試通過。
- 公開介面 smoke test 通過，內部 promote、release 與身分比對資料仍不可由匿名角色讀取。

## 容量

- 隔離正式環境：310 MiB（325,471,379 bytes）。
- 2010 批次完成後基準：310 MiB。
- 本批未使四捨五入後的 MiB 增加。
- 仍低於專案 350 MiB 警戒線與 Supabase Free 500 MiB 上限。
