# 2010 地方議員選舉分批公開紀錄

## 範圍

- 選舉：`2010年直轄市議員選舉`
- 投票日：`2010-11-27`
- 涵蓋區域：新北市、臺北市、臺中市、臺南市、高雄市
- 選區：69
- 候選人：646
- Canonical 人物：646
- 本批僅處理 2010 年直轄市議員選舉，不包含 2009 年及更早資料。

投票日另以中央選舉委員會公告確認：
`https://web.cec.gov.tw/central/article/19467`

## 公開規則

- 公開選舉、選區與候選人紀錄。
- 候選人先經 `person_canonical_map` 解析，只公開 canonical 人物。
- 495 位 canonical 人物先前已公開，本批新增公開 151 位。
- 被合併的來源人物列維持非公開，避免重複人物進入網站。
- 更新 `public.public_people_list_cached` 後執行 `published.promote(NULL)`，同步公開讀取層。

## 正規化與資料品質

- 69 個選區皆屬 `city_councilor`，並對應五個直轄市層級區域。
- 選區名稱沒有 `第01選舉區`、`第02選舉區` 等前導零格式。
- 平地原住民與山地原住民選區維持明確分類。
- 同一選區內沒有 canonical 人物與候選號碼重複。
- 2010 候選人沒有尚待人工處理的人物重複審核項目。
- 候選號碼、政黨、當選狀態與候選資格／結果狀態皆完整。
- 51 筆候選人缺少得票數與得票率，全部位於原住民選區；公開時保留為缺值，不轉成零票。

## 驗證結果

- 核心資料：1 場選舉、69 個公開選區、646 位公開候選人。
- `public.public_candidates`：646 筆。
- `published.elections`：1 筆。
- `published.races`：69 筆。
- `published.candidate_facts`：646 筆。
- 隔離正式環境的匿名角色可讀取 1 場選舉、69 個選區與 646 位候選人。
- 公開介面 smoke test 通過，內部 promote、release 與身分比對資料仍不可由匿名角色讀取。
