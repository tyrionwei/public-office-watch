# 2014 地方議員選舉分批公開紀錄

## 範圍

- 選舉：`2014年直轄市及縣市議員選舉`
- 投票日：`2014-11-29`
- 選區：217
- 候選人：1,600
- Canonical 人物：1,600
- 本批僅處理 2014 年議員選舉，不包含 2010 年及更早資料。

## 公開規則

- 公開選舉、選區與候選人紀錄。
- 候選人先經 `person_canonical_map` 解析，只公開 canonical 人物。
- 被合併的來源人物列維持非公開，避免重複人物進入網站。
- 更新 `public.public_people_list_cached` 後執行 `published.promote(NULL)`，同步公開讀取層。

## 正規化與資料品質

- 選區名稱沒有 `第01選舉區`、`第02選舉區` 等前導零格式。
- 平地原住民與山地原住民選區沿用明確名稱，不合併成一般區域選區。
- 同一選區內沒有 canonical 人物與候選號碼重複。
- 2014 候選人沒有尚待人工處理的人物重複審核項目。
- 156 筆候選人缺少得票數與得票率，全部位於原住民選區；公開時保留為缺值，不轉成零票。

## 驗證結果

- 核心資料：1 場選舉、217 個公開選區、1,600 位公開候選人。
- `public.public_candidates`：1,600 筆。
- `published.elections`：1 筆。
- `published.races`：217 筆。
- `published.candidate_facts`：1,600 筆。
- 隔離正式環境的匿名角色可從 `published.candidates` 讀取 1,600 筆。
- 公開介面 smoke test 通過，內部 promote、release 與身分比對資料仍不可由匿名角色讀取。

## 容量

- 隔離正式環境：309 MiB。
- 前一版基準：約 307 MiB。
- 本批增量：約 2 MiB。
- 仍低於專案 350 MiB 警戒線與 Supabase Free 500 MiB 上限。

## 下一步

2014 批次在本機完成後，再另行盤點 2010 批次；不得由本 migration 自動擴大到更早年份。
