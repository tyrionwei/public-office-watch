# Public Office Watch 功能、資料與排程盤點

盤點日期：2026-08-12
範圍：目前程式、專案文件、本機 Supabase 與既有排程設定。
原則：本文件只安排待辦，不代表允許寫入正式 Supabase、部署、推送或公開敏感資料。

## 1. 結論摘要

目前專案已具備公開讀取層、選舉／人物／政黨頁面、候選人比較、地圖與統計、站內搜尋、回報及本機審核流程；歷年中選會候選人資料與 2026 政黨提名資料也已形成主要資料骨架。

現階段最重要的缺口：

1. Codex App 已安排每日／每週本機蒐集及每日審核；重複的 Windows 工作排程已移除，GitHub 僅保留人工 dry-run。
2. 2026 候選人仍是政黨提名狀態，尚未和中選會正式登記、審定及號次資料對帳。
3. 地方現任名單仍大量由歷史選舉結果推導，缺少持續追蹤遞補、辭職、解職、死亡及罷免後異動的官方名冊流程。
4. 人物經歷、學歷、性別、照片、政治獻金、財產申報、關係網及承諾履行情形仍有明顯資料缺口。
5. 歷年公投模型、28 案官方資料、縣市層級結果與前端結果頁已完成；後續以來源監測和資料校正為主。

## 2. 目前已有功能

### 公開網站

- 首頁：全國／地方摘要、即將到來的選舉、地區議題參與及台灣地圖。
- 選舉：選舉列表、選舉事件、選區頁、候選人比較、政黨表現與學歷分布。
- 人物：人物列表、人物頁、經歷時間軸、資料來源與回報入口。
- 政黨：政黨列表／詳情、人物統計、司法統計、政治獻金及公司彙總圖表。
- 導覽與互動：全站搜尋、更新紀錄、多語系、聊天室及議題參與。

### 本機資料與審核

- 人物 claim 審核與身份可能配對佇列。
- 每日新聞、人物資料補全、司法線索及每週品質監測工具。
- 司法線索的姓名／職位確認、官方裁判書查找及私人待審流程。
- 中選會歷年候選人、2026 政黨提名、中央／地方官方人物頁與政治獻金管線。
- `published` schema、RLS 與公開唯讀資料投影。

## 5. 排程盤點與建議

### 現有排程

| 排程 | 現況 | 風險／限制 |
| --- | --- | --- |
| Codex 每日蒐集 | 每日 18:00 執行 `monitor:daily` | 只保留本機產物；失敗時通知 |
| Codex 每週蒐集 | 每週一 17:00 執行 `monitor:weekly` | 只保留本機產物；失敗時通知 |
| Codex 每日審核 | 每日 21:30，作用中 | 依時間與雜湊審核新 `tmp` 產物 |
| GitHub 資料同步 | 僅允許人工執行 dry-run | 無排程、無正式 Supabase 寫入步驟 |
| 每日司法線索 | 歷史司法新聞搜尋已納入 `monitor:daily` | 新聞只形成私人待審；官方判決搜尋仍由線索觸發 |

目前流程為「Codex App 本機蒐集 → 本機 `tmp` → Codex 每日 21:30 審核」。三個排程共用原工作區，不由 GitHub runner 產生待審檔案。

### 建議增加或調整

1. **P0 每日蒐集（已安排）**：18:00 執行 `monitor:daily`，只寫本機；失敗時標示過期，不以舊檔冒充本次結果。
2. **P0 每週監測（已安排）**：每週一 17:00 執行 `monitor:weekly`，產出 summary、逐步 logs 與內容雜湊。
3. **P0 正式發布人工閘門（已完成）**：GitHub workflow 僅保留人工 dry-run，移除定時觸發與正式 Supabase 寫入步驟。
4. **P0 2026 中選會狀態**：平時每週；2026-08-31 至 09-10 登記期改每日；10 月審定與號次期間改每日。
5. **P1 中選會公投**：每週檢查提案公告、成立案、投票結果與開放資料；投票日前後暫時改每日。
6. **P1 地方現任名冊**：每月比對官方名冊；選舉、罷免或已知人事異動時加跑，只建立異動待審。
7. **P1 官方人物頁／公報**：每週增量抓取，保存原始檔、時間、雜湊與解析版本。
8. **P1 司法查詢**：維持事件觸發；僅有刑事線索時，於司法院服務可用時間搜尋。
9. **P2 每月品質與容量**：檢查來源新鮮度、孤兒 claim、重複 payload、容量與備份可還原性。

## 6. 中選會歷年公投資料與匯入清單

中選會有足以建立第一版歷年公投資料的官方來源：

- [全國性公民投票簡介](https://www.cec.gov.tw/central/article/21443)：公投法施行後共辦理 6 次、21 案，7 案通過、14 案不通過。
- [中選會選舉資料庫－公投](https://db.cec.gov.tw/Referendum)：可查 2004、2008、2018、2021、2025 全國性公投及 2022 憲法修正案公民複決。
- [中選會公投結果列表](https://web.cec.gov.tw/referendum/article/list/3863?page=1)：有各年度案件公告及結果附件。
- [全國性公投計票開放資料](https://data.cec.gov.tw/?dir=%E5%85%A8%E5%9C%8B%E6%80%A7%E5%85%AC%E6%B0%91%E6%8A%95%E7%A5%A8%E8%A8%88%E7%A5%A8%E7%B5%90%E6%9E%9C)：有部分 CSV，較新案件需由結果公告附件補齊。
- [地方性公民投票結果](https://web.cec.gov.tw/referendum/article/32310)：官方彙整可辨識 6 案地方公投。

### 第一批歷史資料

- 全國性公投第 1–21 案：2004、2008、2018、2021、2025。
- 2022 憲法修正案公民複決第 1 案：使用獨立類型／外部編號，不和全國性公投第 1 案合併。
- 地方性公投 6 案：2008 高雄、2009 澎湖、2012 連江、2016 澎湖、2017 金門、2021 新竹市。

### 建模原則與工作分期

- 一個投票日建立一個 election event；每個公投題目建立一個 race。
- 同意／不同意是 ballot options，不得假造成人物 candidate。
- 保存案號、主文、投票權人數、各類票數、投票率、結果、地區分布、來源、附件與內容雜湊。
- **已完成**：全國、憲法修正與地方公投模型，28 案歷史匯入，選票選項、縣市結果、前端結果頁及來源連結。
- **持續維護**：每週檢查新案、公告與結果修正；沒有新案時只記錄查核時間。

## 7. 建議執行順序

1. 維持「Codex App 本機蒐集 → 本機產物 → 21:30 Codex 審核」流程，正式發布另走人工審核程序。
2. 完成 2026 中選會候選人對帳與地方現任名冊監測。
3. 維護已完成的公投資料集，持續監測中選會新案與修正。
4. 依現任及 2026 候選優先補人物資料，再處理獻金、司法及關係網。
5. 最後再擴充財產申報、採購關係、政見履行與贊助模組。
