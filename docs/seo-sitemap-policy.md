# 公開 sitemap / SEO 安全子集

本候選只修改建置與前端，不包含 migration、權限變更或新 RPC。原有 seo_catalog_page（每頁1000）與 seo_share_catalog_page（每頁100）的建置讀取保持原樣，不增加請求；網頁 runtime 不加 DB 查詢。已公開新人物仍由原公開名錄自動納入，不讀樣本檔或姓名白名單。

選區 title/description 與 React 導航 metadata 保留年份。初始 HTML 使用既有公開職位、政黨、日期、地區、公開政見與可用候選姓名；文字 escape，連結限定 catalog 既有公開路徑。摘要最多16行、政見三項各300字。這不是完整學經歷／票數摘要。

人物單列 updated_at 不足以代表整個人物頁；無完整公開 profile 時省略 lastmod。選區缺完整實質異動時間亦省略，不填今天或投票日。其他頁型既有日期不改。

僅村里長參選不等於完整任職史。兩位原排除候選暫保留；mixed、未知、空值保留。可重用 scope 函式只有完整任職史與公開參選史皆已核、非空參選類型全 village_chief 且無較高職級時才允許 sitemap 排除；目前建置沒有傳入此證據，因此不排除人物。不刪頁、不新增 noindex，村里長選舉／選區保留。

完整摘要與全量 profile lastmod 另列未驗收方案，不包含於本 patch。既有公開人物 RPC 每次最多4人，race RPC每次1個；合法重用不需新增資料權限，但全站至少2,624次人物＋27,533次選區呼叫，另有姓名名錄，成本未驗證，不能默默啟用。若要低成本完整輸出，需要獨立審查受限批量RPC契約及成本；不得直接授權公開候選表或切換角色繞過拒絕。

發布仍須最新名錄差異、精確head CI與使用者發布批准。本機樣本導航測試不能證明全站資料完整，也不保證Google收錄。
