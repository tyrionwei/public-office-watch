## 2. 圖表共同正規化

- 政黨：先合併既有別名，例如 `基進黨` 歸入 `台灣基進`、`無` 歸入 `無黨籍`。
- 選舉類型：沿用網站既有選舉分類，不另建一套互相衝突的名稱。
- 學歷：以最高已確認層級分組；`大專` 與 `高中職以下` 保留為未細分類別，不自行推定更精確學歷。
- 當選／參選比例：分母使用特定選舉與職位的候選紀錄，不能把不同年份或不同層級混成一個比例。
- 人物屬性比例：分母使用去重後的 canonical person，避免同一人歷年多次參選而被重複計入。

## 3. 刑事司法紀錄圖表口徑

建議標題：

> 已確認刑事司法紀錄

建議備註：

> 僅統計本站已完成身分與來源核對、目前公開的刑事司法紀錄；未收錄不代表無相關紀錄，數值可能隨後續查證與司法進度調整。

不使用「犯罪率」、「有前科比例」或「實際情況只會更多」。案件可能因同名排除、重複合併、無罪判決或後續審級結果而增加或減少。

只納入同時符合下列條件的紀錄：

- `claim_type = legal_case`
- `review_status = verified`
- `visibility = public`
- `is_public = true`
- `claim_json.recordType = criminal`

行政裁罰、選舉民事當選無效與歷史稱號不得併入刑事統計。每位人物依目前最明確結果只進入一個類別：

| 類別 | 目前人物數 | 說明 |
| --- | ---: | --- |
| 確定有罪紀錄 | 58 | 至少一筆已確認確定判決或等價的歷史確定紀錄 |
| 未定讞或結果未明 | 32 | 起訴、偵審中、未定讞判決或結果尚未完整確認 |
| 僅有無罪結果 | 4 | 目前公開刑事紀錄只有無罪類結果 |
| 合計 | 94 | 去重後人物數 |

政黨或選舉頁若顯示比例，分母應是該頁面範圍內去重後的人物數，並保留上述三種結果，不把它們合稱為已定罪。

## 6. 建議實作順序

1. 政黨頁：同一選舉／職位的參選與當選比例。
2. 政黨頁：已確認刑事司法紀錄，使用三段結果與範圍備註。
3. 人物或選舉範圍：最高學歷分布，固定顯示「未提供」。
4. 縣市與選舉頁：在相同年份及相同職位下比較政黨與候選人結構。
5. 完成視覺稿後，再評估是否需要額外的 published 聚合表；先不為尚未證實的效能問題複製資料。
