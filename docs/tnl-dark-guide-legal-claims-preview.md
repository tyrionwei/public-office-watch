## 32 條安全預覽

| 預覽類型 | 數量 |
|---|---:|
| 刑事紀錄／程序 | 21 |
| 民事當選無效 | 8 |
| 行政裁罰／彈劾 | 2 |

所有預覽都符合以下限制：

- reviewStatus = pending
- visibility = review_only
- isPublic = false
- legalCasePublicEligible = false
- publicationGate.requiresHumanApproval = true
- claim 顯示文字只取自獨立來源的支持摘要，不直接發布暗公報原文。
- 官方來源最高 A；媒體來源最高 B。
- 網友留言、未知或一般二級來源不進安全預覽。

## 發布前優先人工檢查

原始 32 條中有以下交疊風險；同一條可能同時屬於多類：

- 10 條需要確認是否已有更晚判決或案件結果。
- 5 條涉及樁腳行為，不能把樁腳刑責直接歸給候選人。
- 8 條屬民事當選無效，不能直接描述為候選人刑事有罪。
- 2 條屬行政裁罰或彈劾，不能描述為刑事定罪。
- 1 條是歷史「十大槍擊要犯」標籤，需要額外脈絡，不宜只顯示標籤。

## 使用方式

本機 Supabase 啟動後執行：

    npm run preview:tnl-dark-guide-legal-claims
    node --test scripts/preview-tnl-dark-guide-legal-claims.test.mjs

輸出：

- local-data/tnl-dark-guide-legal-claims-preview.json
- classifiedRecords：177 條分類。
- plannedClaims：目前為 0；原始 32 條安全候選均已進入本機已驗證紀錄。
- held：安全閘門未通過項目。
- alreadyPublic：已存在的公開紀錄。
- alreadyReviewed：已核對且保留在 review-only 的紀錄，不會再次列入待審核。

local-data 已被 Git 忽略，不會部署。
