# POW 2026-11-27 合版發布分支

範圍：支援頁、2026 大選投開票所及候選人公報補值，同一版交付。排除村里長。此分支尚未推送、合併、部署，也未對正式資料庫執行。

## 程式與資料分開

- 遠端 main 基準 `0a84937237dd0265f7dfb55a5dc2f9b11570f6b3`; support base `0f561259b2bf57de5e652b12c8494b3164433f18`. 只納已驗收的 6 個檔案。測試版候選人、測試快照來源 ID、收款設定及測試執行環境不進 Git。
- `supabase/migrations/20261127055704_pow_20261127_combined_release_receipt.sql` 只建立限資料庫操作角色使用的暫存和收據表。無公開 RPC，無瀏覽器存取，無正式資料變更或自動啟用。
- `prepare.py <合版審查目錄> <不存在的私有輸出目錄>` 核查原審查清單 SHA-256、鍵、筆數及排除範圍，輸出 `stage.sql` 和雜湊。資料包放 WSL 的 `local-data`，不要提交。兩地遷址 metadata、前後快照與官方 PDF 另對照發版分支鎖定的審查原件雜湊；暫存 SQL 也核對兩筆新址、所名及來源。載入前執行 `sha256sum -c SHA256SUMS`，並確認 SQL 僅在指定隔離庫或另經授權的暫存環境執行。
- `verify-stage.sql` 驗證候選人 2,529 欄／1,164 筆參選、雲林 501 與澎湖 111 所、4,152 鄰別鍵、兩筆遷址官方原件雜湊、63 村里不套用，以及匿名／登入／服務 API 角色皆無存取。147 所仍走中選會，不承諾全國唯一導航。
- `verify-db-baseline.sql` 是唯讀護欄，要求兩支已核 migration 已登記，且生日同步函式、觸發器、權限及官方來源 view 的精確指紋相符，不是正式匯入。核對正式 baseline `14fdb601-fbdf-4587-9804-c949f5ef266f`、候選人正規歷史 ID、正式前值、候選資格範圍、同欄主張及兩筆遷址前值；任何差異立即停止，不做模糊匹配。經正式前再次唯讀演練才採用。此程式不替代完整兩縣來源、鄰別、版本與前後雜湊檢查。
- `reset-private-stage.sql` 只退回尚未採用的本批暫存。不含 schema DROP、不觸碰公開表。必須帶入三份 JSON 的 SHA-256（參數 `candidates_sha256`、`polling_sha256`、`provenance_sha256`）。預設回滾；僅經授權且確認目的資料庫後才設 `commit_private_stage_reset=true`。

1. 把隔離驗收做過的正式主張與站所切換整理為可於**正式同版 schema 的獨立還原庫**跑完的採用／回復交易，不得直接搬用測試 SQL 或測試 ID。申請正式操作前保留 2,529 欄前後值和精確主張 ID、完整四縣來源收據與新舊快照；回復不得刪除已產生履約投票或分享相依的主張。回退站所時，兩筆已知遷址至少走官方連結，不能回到錯址導航。
2. 以既有程序讀回確認生效後，核對 Cloudflare 正式部署目標和上一版回復 ID，再排定同版切換。先檢視 GitHub Production Release 工作流程：合併 main 並通過 Web CI 會自動觸發部署，migration drift 檢查不替你執行 migration。**不能為了測試先合併 main**；正式切換、資料寫入、核准狀態應另有執行門檻。
